# CLI 使用指南 — GCD 快速上手

> 内置设计 + 默认参数 + 精简模式 = 2 分钟跑完

## 全程操作记录

```
$ python3 cli.py

第一步: 选择设计
  [1] GCD        → 回车（默认）
  ✅ GCD (最大公约数)

第二步: 选择工艺
  [1] sky130     → 回车（默认）
  ✅ sky130

第三步: 选择需求
  [1] 开源       → 回车（默认 1,2）  只选了开源, 不选低功耗
  ✅ ['开源']

第四步: 设计目标
  [1] 简单模式    → 回车（默认）
  频率 MHz       → 回车（默认 200）
  面积上限       → 回车（跳过, 不限）
  功耗上限       → 回车（跳过, 不限）
  ✅ freq=200MHz

第五步: 流程深度
  [2] 精简       → 输入 2（只要 synth + STA, 几秒跑完）
  ✅ 精简

═══════════════════════════════════════════
  Flow: Yosys → OpenSTA (2 步)
  1. synthesis    Yosys      可换: Design Compiler
  2. STA          OpenSTA    可换: PrimeTime
═══════════════════════════════════════════

第六步: 替换工具?
  回车 → 不替换

第七步: 执行模式
  [1] 执行一遍    → 输入 1（跑完就停, 自己看结果）
```

## 关键决策点

| 步骤 | 你选了 | 可选的其他值 |
|------|--------|------------|
| 设计 | GCD | AES(253行) / UART(113行) / 自定义 |
| 工艺 | sky130 | ASAP7 / tsmc3 / tsmc5 / gf22 |
| 需求 | 开源 | 低功耗/面积/快速/新手/签核/极致/AI训练 |
| 频率 | 200MHz | 填任意数值, 如 500=500MHz |
| 流程 | 精简 2 步 | 完整 12 步(有面积/功耗目标时) |
| 执行 | 跑一遍 | 迭代优化(自动诊断→重跑) |
